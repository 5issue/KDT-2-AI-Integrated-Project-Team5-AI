# 아키텍처 문서

깃허브 위키에 그대로 붙여 넣을 수 있게 만든 mermaid 다이어그램 모음입니다.
파일 하나가 위키 페이지 하나입니다. 본문을 통째로 복사하면 됩니다.

| 페이지 | 무엇을 그렸나 | 다이어그램 |
| --- | --- | ---: |
| `overview.md` | 시스템 전체, 폴더 의존 방향, 핵심 데이터 모델 | 3 |
| `data-pipeline.md` | LLM 3단계, 직접 적재 경로, 패키지 계층, 분할 패키지 공통 구조 | 4 |
| `recsys-sql.md` | SQL 카탈로그 구조, 보유 판정과 추천 흐름, 버블 | 3 |
| `rag-lab.md` | 추천 문구 경로, 검색 그래프와 LLM 공급자 | 2 |
| `serving.md` | 모듈 의존, 요청 한 번의 시퀀스 | 2 |

## 그리는 규칙

- **다이어그램 하나에 컴포넌트 8개 이하.** 넘으면 그림이 작아져 읽을 수 없습니다.
  넘칠 것 같으면 다이어그램을 하나 더 만듭니다.
- 라벨은 한 줄로 짧게. 설명은 그림 아래 본문에 씁니다.
- 실선 화살표는 코드 의존(import / 호출), 점선은 데이터나 설정이 흘러가는 방향입니다.
- 코드가 바뀌면 그림도 같이 고칩니다. 그림이 코드보다 오래되면 없느니만 못합니다.

## 위키에 붙일 때

깃허브 위키는 마크다운 안의 ` ```mermaid ` 코드 블록을 그대로 렌더링합니다.
파일 내용을 통째로 새 페이지에 붙여 넣으면 됩니다. 파일 사이의 링크는 위키 페이지
이름으로 바꿔 주세요(`overview.md` -> `[[Overview]]`).
