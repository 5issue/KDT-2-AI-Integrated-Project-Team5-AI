## ai팀 협업 방식

3명이 각자 추천을 위한 SQL + RAG 실험환경을 위해 각각 폴더를 열고 작업한다.

## 날짜별 계획 (임시안)

9.7~9.9: 깃허브 폴더 스캐폴딩 -> openai/claude batch api로 파싱 + Neon에 데이터 적재

9.9~9.11: 레시피 검색 SQL문에 집중 + pytest로 검증

9.14~9.18: RAG로 추천문구 생성 및 my recipe 생성 -> 서빙 API 계약에 맞추어 구현 -> 통합테스트 (팀5 mvp 마감기한)

9.20~9.22: Fastapi 배포(llm배포는 나중으로 생각) + FE와 인터페이스 실제로 맞추기. -> RAG 답변 모니터링 및 평가 (골든 데이터셋 기반 간단히)

9.28~10.2: phase4 문서 작성 + 골든 데이터셋 평가(아마도) + ai팀 발표자료 간략 구성 + E2E QA
